How to Add a New Show

No HTML editing needed. Just update the spreadsheet, run one command, and push.

Step 1 — Update the spreadsheet

  1. Open shows.xlsx in the repo root (double-click it in Finder).
  2. Scroll to the bottom of the data and add a new row.
  3. Fill in at minimum: Date (format: 2026-07-04) and Venue Name.
  4. Fill in any optional columns — time, URL, description, etc. See the Column Guide tab for what each column does.
  5. Save and close the file (Cmd + S, then close Excel).

Step 2 — Open Terminal

  1. Press Cmd + Space to open Spotlight.
  2. Type Terminal and press Return.
  3. A black (or white) window with a blinking cursor will appear. That's Terminal.

Step 3 — Navigate to the repo folder

Type this and press Return:

cd ~/Documents/kings_website/rock

The prompt will now show you're inside the repo folder. Nothing else visible will happen — that's normal.

Step 4 — Run the script

Type this and press Return:

python3 scripts/update_shows.py

You should see: Wrote 23 shows to shows.json (or however many shows you have).

First time only — if you see "Missing dependency", run this first:
pip3 install openpyxl
Then re-run the script above.

Step 5 — Commit and push with GitHub Desktop

  1. Open GitHub Desktop.
  2. You'll see shows.xlsx and shows.json listed as changed files on the left.
  3. In the bottom-left, type a short summary — e.g. add show: Venue Name on YYYY-MM-DD.
  4. Click Commit to main.
  5. Click Push origin in the top right.

GitHub Pages will rebuild in under a minute and the show will appear on the site.

Tip — You can check the live site at kingsofewing.com/#shows after a minute to confirm it worked.
