# Kings of Ewing — Brand System (2026)

A bold, genre-neutral identity built to work everywhere the band plays: weddings,
block parties, fundraisers, posters, and social. The mark is a stacked condensed
wordmark with a single signal-red bar as its signature device.

## Logo

**Primary logo** — `Kings_of_Ewing_Logo_2026.svg` (for light backgrounds) and
`Kings_of_Ewing_Logo_2026_reversed.svg` (for dark backgrounds). "KINGS" sits above
"OF EWING," anchored by a vertical red bar on the left.

**Icon / submark** — `Kings_of_Ewing_Icon.svg`. A KOE monogram on an ink-black
rounded tile with the red bar underline. Use for profile avatars, favicons, and
stickers. The square crops cleanly to a circle for Instagram.

### Clear space and sizing
Keep clear space around the logo equal to the height of the red bar on all sides.
Don't place the logo on busy photos without a solid backing shape. Minimum legible
width for the primary logo is about 120px; below that, use the icon instead.

### Don'ts
Don't recolor the wordmark outside the palette, don't stretch or condense it
further, don't add drop shadows or outlines, and don't separate "OF EWING" from
"KINGS" in the lockup.

## Color palette

| Role | Name | Hex |
|------|------|-----|
| Primary / text | Ink Black | `#141414` |
| Accent | Signal Red | `#e23b2e` |
| Light / paper | Bone | `#ededea` |
| Body text on light | Slate Gray | `#4a4a48` |

Ink Black and Bone are the workhorses; Signal Red is the accent — use it
sparingly (the bar, "OF EWING," links, highlights) so it stays loud.

## Typography

**Display — Anton.** The logo face. Use for big headlines, poster titles, and
section headers. All caps. Google Fonts: `Anton`.

**Subheads / labels — Oswald.** Condensed sans that pairs naturally with Anton.
Use for dates, venue names, buttons, and overlines. Google Fonts: `Oswald`
(500 and 700).

**Body — Inter.** A clean, highly readable humanist sans for paragraphs, captions,
and email copy. Google Fonts: `Inter` (400 and 600).

```
@import url('https://fonts.googleapis.com/css2?family=Anton&family=Oswald:wght@500;700&family=Inter:wght@400;600&display=swap');
```

## Notes
The SVG logos load Anton from Google Fonts (same pattern as the existing sticker
file). If you want fully self-contained files for print or offline use, the
