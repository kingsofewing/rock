How to Add a New Show

No HTML editing needed. Just update the spreadsheet, run one command, and push.

Step 1 — Update the spreadsheet

  1. Open shows.xlsx (in this folder).
  2. Go to the Shows tab and add a new row at the bottom.
  3. Required: Date (format: 2026-07-04) and Venue Name.
  4. Fill in any optional columns — time, URL, description, etc. See the Column Guide tab for what each column does.
  5. Save and close the file (Cmd + S, then close Excel). The script will fail if the file is still open.

Step 2 — Open Terminal

  1. Press Cmd + Space to open Spotlight.
  2. Type Terminal and press Return.

Step 3 — Navigate to the repo folder

cd ~/Documents/kings_website/rock

Step 4 — Run the script

python3 docs/shows/update_shows.py

You should see: Wrote XX shows to shows.json

First time only — if you see "Missing dependency", run this first, then re-run the script:

pip3 install openpyxl

Step 5 — Commit and push via GitHub Desktop

  1. Open GitHub Desktop.
  2. You'll see shows.xlsx and shows.json listed as changed files.
  3. Type a summary in the bottom-left — e.g. add show: Venue Name.
  4. Click Commit to main.
  5. Click Push origin (top right).

GitHub Pages rebuilds in under a minute. Check kingsofewing.com/#shows to confirm.
